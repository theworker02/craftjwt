# craftjwt

Craft digests and jwt fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/craftjwt/

## Install / run

```bash
git clone https://github.com/theworker02/craftjwt.git
cd craftjwt
node src/cli.js
node --test
```
